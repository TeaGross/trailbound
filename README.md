# Trailbound 🥾

Trailbound is a hiking discovery website built with Angular and TypeScript. The project is part of my journey to revisit and strengthen my understanding of Angular fundamentals through hands-on practice.

The goal is to create a platform where users can explore hiking trails from around the world and discover their next adventure.

### 🚧 Work in progress!

This project is currently under development. New features and improvements are being added as I continue learning and building with Angular.

## Angular fundamentals

This project demonstrates my understanding and practical use of core Angular concepts:

* Components: Building a component-based application with a clear structure.

* Templates and data binding: Displaying dynamic data in Angular templates.

* TypeScript interfaces: Defining structured and type-safe data models.

* Routing: Navigating between views using Angular Router and RouterLink.

* Component communication: Passing data between components where needed.
